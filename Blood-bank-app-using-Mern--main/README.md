# Blood Bank App Using MERN Stack

## Description
This is a full-stack web application developed using the MERN stack (MongoDB, Express.js, React, Node.js). The app allows users to register as blood donors, request blood, and view available donations. It provides a user-friendly interface for donors and those in need of blood.

## Features
- **Donor Registration:** Users can sign up as blood donors.
- **Blood Requests:** Users can request blood by specifying the type and quantity.
- **User Interface:** A clean and responsive interface built using React.
- **Admin Panel:** Admin can manage donor registrations and blood requests.

## Installation

### Prerequisites
- Node.js
- MongoDB
