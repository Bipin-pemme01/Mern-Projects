# MERN Projects

This repository contains a collection of various MERN (MongoDB, Express.js, React.js, Node.js) stack applications. Each project demonstrates the usage of the MERN stack for building full-stack web applications, ranging from simple CRUD applications to more complex systems with features like user authentication, real-time updates, and more.

### Projects in this Repository

1. **[Blood Bank App using MERN](https://github.com/Bipin-pemme01/Mern-Projects/tree/main/Blood-bank-app-using-Mern--main)**  
   A blood bank management system that allows users to register as blood donors, request blood, and view available donations. The application has user and admin roles, with functionality for managing blood donors and requests.

2. **[E-Commerce App using MERN](https://github.com/Bipin-pemme01/Mern-Projects/tree/main/E-Commerce-app-using-mern-main)**  
   A full-fledged e-commerce website built with the MERN stack, featuring user authentication, product listing, cart management, and order processing.

3. **[Online Food Store](https://github.com/Bipin-pemme01/Mern-Projects/tree/main/Online-food-store-main)**  
   A food delivery application that allows users to browse food items, place orders, and manage their cart. Includes both customer and admin functionalities.

## Prerequisites

To run these projects locally, ensure that the following software is installed on your system:

- **Node.js** (Recommended version: 14.x or later)
- **MongoDB** (or MongoDB Atlas for cloud-based MongoDB)
- **npm** (Node Package Manager) which comes with Node.js
- **Git** (for cloning repositories)
